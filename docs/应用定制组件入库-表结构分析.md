# 应用定制组件入库 - 组件库表结构分析

> 分析日期：2026-07-27
> 状态：表结构分析完成，入库功能 PRD 待设计
> 数据库：GaussDB (openGauss, USTORE)

## 表分组（8张）

### 公共组件（原子库）— 3张
| 表名 | 角色 | PK | 核心字段 |
|------|------|-----|---------|
| `iop_mc_serv_info` | 组件主表 | serviceid varchar(17) | servicename, servicecnname, confstatus, servicetype, platformtype, templatetype, templateid, batchexecflag, timeoutsecond |
| `iop_mc_serv_parm_rln` | 组件-参数关联 | servicename+parmrlntype+orderindex (联合) | parmname |
| `iop_mc_serv_parm_info` | 参数定义 | parmid varchar(17) | parmname, parmcnname, datatype(控件类型), datavalue(默认值), encryptflag, parmcheckflag, parmcheckapiid(正则) |

### 应用定制（定制库）— 3张
| 表名 | 角色 | PK | 与公共表差异 |
|------|------|-----|-------------|
| `iop_mc_app_serv_info` | 定制组件主表 | serviceid varchar(17) | 多了 categorycode varchar(20) |
| `iop_mc_app_serv_parm_rln` | 定制关联表 | servicename+parmrlntype+orderindex+categorycode | 多了 categorycode |
| `iop_mc_app_parm_info` | 定制参数定义 | parmid varchar(17) | 多了 categorycode |

### 实例（固化配置）— 2张
| 表名 | 角色 | PK | 核心字段 |
|------|------|-----|---------|
| `iop_mc_serv_ins_info` | 实例主表 | instanceid varchar(17) | serviceid(→公共组件), instancename, confstatus, datavalue(8000), successrule(clob), categorycode, servicetype, res1(上送渠道) |
| `iop_mc_serv_ins_parm` | 实例参数 | instanceid+parmorder (联合) | parmname, datavalue(10000), parmsrce(参数来源) |

## ER 关系

```
公共组件:
  serv_info ──(servicename)──→ serv_parm_rln ──(parmname)──→ serv_parm_info

应用定制:
  app_serv_info ──(servicename)──→ app_serv_parm_rln ──(parmname)──→ app_parm_info
  （三表均多 categorycode 字段）

实例:
  serv_ins_info.serviceid ──→ serv_info.serviceid (来源公共组件)
  serv_ins_info ──(instanceid)──→ serv_ins_parm
```

⚠️ 关联表用 servicename(名称) 做 JOIN 键，非 serviceid(ID)

## 状态机 (confstatus)

```
2(草稿) → 3(待审批) → 1(启用/入库)
                ↘ 驳回 → 2(草稿)
1(启用) → 4(禁用)
```

审批链路: approver / approvalid / workordid(工单号)

## 参数控件映射 (datatype)

| 值 | 控件 | 前端 ParamField type |
|----|------|---------------------|
| 0/NULL | input 输入框 | input |
| 1 | 单选框 | select (radio) |
| 2 | 多选框 | checkbox |
| 3 | 时间下拉框 | date |
| 4 | 计数器 | input (number) |

## 参数校验 (parmcheckflag)

| 值 | 含义 |
|----|------|
| 0 | 可空 + 不校验 |
| 1 | 可空 + 需校验(正则) |
| 2 | 必填 + 不校验 |
| 3 | 必填 + 校验 |

校验正则存 parmcheckapiid 字段

## datavalue 双重语义

- 参数定义表(parm_info): 预设默认值 → 有值时工作台不显示输入框，直接用此值
- 实例参数表(serv_ins_parm): 固化后的实际执行值

## 审计字段（所有表统一）

creator, createtime, modifier, modifytime, approver, approvalid, workordid, res1-res5

## 发现的问题

| # | 问题 | 严重度 |
|---|------|--------|
| 1 | 关联表用 servicename 做 JOIN 键（非ID），名称变更即断链 | 🔴 高 |
| 2 | orderindex varchar(2)，最多99参数，字符串排序 "10"<"2" | 🟡 中 |
| 3 | confstatus 长度不一致（公共1/app2/实例1） | 🟡 中 |
| 4 | 时间字段 varchar(20)，无法DB层时间运算 | 🟡 中 |
| 5 | 关联表无显式 PK/FK 约束 | 🟡 中 |
| 6 | res1-res5 各表含义不同，无统一文档 | 🟢 低 |
| 7 | 公共表 vs 定制表高度重复，可考虑单表+type区分 | 🟢 低 |

## 与前端 CustomDraft 状态映射

| 前端 status | DB confstatus | 含义 |
|-------------|---------------|------|
| draft | 2 | 草稿 |
| submitted | 3 | 待审批 |
| published | 1 | 已入库(启用) |
| rejected | 2(退回)/4(禁用) | 驳回 |
