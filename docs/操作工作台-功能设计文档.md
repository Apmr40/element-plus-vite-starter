## 页面结构（4 个区域）

### 1. 顶部栏
- 应用系统选择器（8 个模块）
- 执行历史按钮 → 打开抽屉

### 2. 最近执行状态栏
- 横向展示最近操作/编排执行记录
- 状态图标 + Tag + 来源标记（组件/编排）+ 可关闭
- 点击 → 执行详情 / 编排历史抽屉

### 3. 操作组件区域（三大分区 Tab）

**我的收藏：**
- 收藏操作卡片 + 分类筛选标签

**公共组件：**
- 8 个一级分类 Tab：操作系统/数据库/中间件/负载均衡/应用平台/CCE/大数据平台/人行演练专用
- 二级目录卡片 → 操作卡片网格（面包屑返回）
- 卡片：名称 + 收藏星标 + 标签 + 执行次数

**应用定制：**
- 正式操作 / 我的草稿 子 Tab
- 正式操作 dropdown：编辑/查看草稿/删除/复制
- 草稿：勾选 → 批量发布（批次弹窗）/ 批量删除

### 4. 操作编排区域
- 正式编排 / 我的草稿 子 Tab
- 编排卡片：流程图缩略图 + 标签 + dropdown
- 操作按钮：新增编排、快速修改标签、筛选

## 执行流程（两步式弹窗）

```
点击操作卡片
→ Step1: 参数配置弹窗
  ├─ 动态表单（ParamField: input/select/date/textarea/checkbox）
  ├─ 资源选择：机房→集群→命名空间→Deployment 四级级联
  └─ POD 列表（名称/IP/状态）
→ 确认执行
→ Step2: 执行结果弹窗
  ├─ 轮询模拟（2s 完成）
  └─ 执行明细表格（S/F/P/R 状态）
```

## 类型体系

- `OperationComponent`：操作组件（分类/子分类/风险等级/标签/参数配置）
- `Orchestration`：编排（步骤数/状态/参数配置）
- `ExecutionRecord`：执行记录（类型/状态/明细）
- `ExecutionDetail`：执行明细（S/F/P/R）
- `OrchestrationExecutionRecord`：编排执行记录（含作业明细）
- `ParamField`：参数字段（5 种类型）
- `CustomDraft` / `ScenarioDraft`：草稿（draft/submitted/published/rejected）
- `PublishBatch`：发布批次
