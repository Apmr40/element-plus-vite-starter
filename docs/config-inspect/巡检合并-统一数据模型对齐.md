## 2. 统一模型 ↔ 真实表结构映射

```
InspectStrategy（策略）─────┐  iop_mc_inspect_strategy（现有，不动）
InspectPlan（计划）─────────┤  iop_mc_inspect_plan（现有，不动）
                            ↓
InspectExecution（执行批次）   iop_mc_inspect_execution（job_id 主键）
  └─ records: InspectExecDetail[]   iop_mc_inspect_exec_detail（唯一事实源）
       ├─ check_name / host_name / ip / resource_type / obj_name
       ├─ std_value / current_value / result_status
       ├─ 例外内嵌：exception_remark / exception_applicant / exception_apply_time + 例外标记
       └─ governId?（关联治理单）

派生/关联：
  AppSummary   = GROUP BY records（demo 汇总视图，字段语义对齐 iop_mc_inspect_summary）
  InspectGovern    iop_mc_inspect_govern（治理表，前端呈现为"整改工单"）
  InspectException iop_mc_inspect_exception（例外审批表，双轨）
  InspectExecMiss  iop_mc_inspect_exec_miss（缺失结果，现有已实现）
```

### 逐表对齐结论

| 统一模型 | 真实表 | 结论 |
|---|---|---|
| InspectExecution | iop_mc_inspect_execution | 新增，批次主键 job_id，含 plan_id/strategy_id/exec_status |
| InspectExecDetail | iop_mc_inspect_exec_detail | **唯一事实源**；现有 InspectResult 字段已对齐，改名收编 |
| AppSummary | iop_mc_inspect_summary | 真实表按模块(category)+日期聚合；demo 按应用派生，字段语义对齐 check_num/abnormal_num/tar_num |
| InspectGovern | iop_mc_inspect_govern | **替代 demo Order**；联合主键 check_name+obj_name+host_name，remain_time 整改时限 |
| InspectException | iop_mc_inspect_exception | 独立审批表：状态流（审批中/通过/取消中/取消通过）+ work_order_id |
| InspectExecMiss | iop_mc_inspect_exec_miss | 现有"缺失结果查询"已实现，保留 |

profile 文档《TASK-20260423-003_巡检详情页交互设计》的原型（应用级详情抽屉）与方案①"弃用抽屉改钻取"不冲突，其设计元素被吸收：

| 原详情页区块 | 吸收为 |
|---|---|

| 关联操作区（工单） | 汇总行"创建工单" → govern |

## 4. 冲突裁决记录

| # | 冲突 | 裁决 |
|---|---|---|
| 1 | demo 类型 camelCase vs 真实表 snake_case | 统一模型以真实表字段语义为准；`types/inspection.ts` 中 InspectionResult/Order 废弃 |
| 2 | 工单 vs 治理表 | 前端保留"工单"叫法（PRD 口径），数据模型落 govern |
| 3 | 汇总按应用 vs summary 按模块 | demo 汇总视图按应用聚合，字段语义对齐 summary 表 |
| 4 | 例外单轨（内嵌）vs 双轨 | 双轨：明细内嵌标记（展示）+ exception 列表（审批状态） |
| 5 | 详情抽屉去留 | 方案①：弃用抽屉，钻取到明细视图（已确认） |
| 6 | 例外审批流 UI 做不做 | **不做 UI，数据模型预留**：类型保留审批状态枚举（审批中/通过/取消中/取消通过），demo 例外申请即生效（status 直接置"通过"），接真 API 时启用审批流（2026-08-17 决策） |
| 7 | 汇总视图聚合维度 | **按应用聚合**（贴合原巡检管理页面），字段语义对齐 iop_mc_inspect_summary（2026-08-17 决策） |
