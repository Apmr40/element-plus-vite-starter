# 筛选条收纳方案 — 交互设计

> 状态：**已实现** · 2026-08-09（FilterEntry/FilterChips 组件 + useOperationFilter 展开态）
> 背景：当前 FilterBar 常驻占 ~70px 高度，三个区域（应用定制/公共组件/收藏）都占空间

## 核心思路

**"筛选"按钮触发展开/收起，收起时零额外占位，激活条件以可移除 chip 内联显示在按钮旁。**

## 三态交互

| 状态 | 呈现 | 占位 |
|---|---|---|
| 无筛选 + 收起（默认） | 工具栏仅多一个「筛选」按钮（Filter 图标） | **0 额外行** |
| 有筛选 + 收起 | 「筛选」按钮高亮（主色）+ 按钮旁内联 chips：`操作分类:启停 ×` `标签:核心链路 ×` … 末尾「清除」文字链 | 0 额外行（chips 内联在按钮所在行） |
| 展开 | 按钮激活态（图标旋转/底色）+ 下方展开完整 FilterBar（现有组件不动） | ~70px（仅操作筛选时） |

**交互规则**：
- 点「筛选」按钮 = toggle 展开/收起，带高度过渡动画（~200ms）
- chip 点 `×` = 移除单个条件（分类 chip 移除即回到"全部"；标签 chip 逐个移除）
- 「清除」= 一键清空所有条件（复用 `resetOperationFilters`）
- 有激活筛选时**不自动展开**——chips 已经表达了条件，面板只在用户主动调整时打开
- 面板内操作实时生效（与现状一致），收起不丢失筛选状态

## 三个区域的按钮落位（都复用现有行，不新增行）

| 区域 | 按钮位置 |
|---|---|
| 应用定制 | `custom-tab-actions`（视图切换器右侧、新增操作左侧）——就是原来被移除的"筛选"按钮位置，回归 |
| 公共组件（二级列表） | 面包屑行（breadcrumb-bar）右侧 |
| 我的收藏 | 现有一级分类筛选行（favorite-filter）右侧 |

## 技术改动点

1. `useOperationFilter.ts` 增加 `filterExpanded` ref + 激活条件 chips 的 computed（`{type:'category'|'tag', value}[]`）——跨 tab 共享（筛选状态本来就是共享的）
2. **新增 `FilterChips.vue`**（~60 行）：chips 渲染 + 单个移除，纯渲染
3. `FilterBar.vue` 改为受控：增加 `v-if` 包裹（展开才渲染），自身不感知按钮——按钮和 chips 由页面工具栏组合，保持 FilterBar 单一职责
4. `index.vue` 三处工具栏加「筛选」按钮 + `<FilterChips>` 内联；面板区 `v-if="filterExpanded"` 包 FilterBar
5. 切分区清空筛选时 chips 自动消失（已有 `resetOperationFilters` 联动，无需额外逻辑）

## 边界

- 展开状态**不持久化**（筛选本身不持久化，每次进页面默认收起）
- 批量加标签模式与筛选面板可同时存在，互不干扰（两个独立行）
- 筛选后结果为空 → 空态文案「无匹配数据，试试清除筛选」仍有效（chips 也提供了清除入口）

## 空间收益

默认态从 ~70px → 0px；有筛选条件时仅一行工具栏内联 chips（~32px），且用户随时可收。
