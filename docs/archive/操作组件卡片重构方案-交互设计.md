# 操作组件卡片重构方案 — 交互设计

> 状态：**已实现** · 2026-08-09（280px 列宽 + 三层骨架 + 正在编辑文字链）
> 范围：操作组件分区卡片视图（公共组件 / 应用定制 / 我的收藏）

## 1. 背景与问题诊断

| 问题 | 根因 |
|---|---|
| 卡片太窄，标签挤成 2-3 行 | grid 最小列宽只有 220px，定制卡最多有 定制+2权限提示+5自定义标签 = 8 个 tag |
| 标题行拥挤（定制卡） | 正在编辑徽章 + V3 + 标题 + ⋮菜单 全挤在一行，标题被压缩到 ~100px |
| 两种卡片结构不一致 | 公共卡右上角是 ⭐收藏，定制卡是 ⋮菜单；footer 内容不同，视觉节奏对不齐 |
| 行间距过密 | title/tags/footer 三层间距只有 4px，属性边界糊在一起 |

## 2. 核心设计决策

1. **三层骨架统一**：公共/定制/收藏卡片共用同一结构，仅按 tab 裁剪元素
2. **标签区不拆行、不加组标签**：两类标签（权限提示=实色 / 自定义=描边）靠视觉编码自区分，双重编码（组标签）降低信息密度
3. **「定制」徽标移出标签区**：应用定制 tab 内去掉（分区上下文已表达），收藏区保留（混合列表需区分来源）
4. **「正在编辑」移入标题区，采用文字链形式**（选项 A，用户已确认）

## 3. 卡片结构（定稿）

```
┌────────────────────────────────────────┐
│ [V3] 定制应用健康检查 …  ✎正在编辑  ⋮  │ ← 标题区：版本徽章+名称+编辑状态+菜单
│                                        │
│ [仅生产] [应急] [核心链路]              │ ← 标签区：权限提示(实色)+自定义(描边)
│                                        │
│ 执行次数: 128 · 更新: 2024-01-15   ℹ   │ ← 信息区
└────────────────────────────────────────┘
```

### 3.1 各层按 tab 裁剪

| 层 | 公共组件 | 应用定制 | 我的收藏 |
|---|---|---|---|
| 第1层 标题区 | 标题 + ⭐收藏 | [V3]版本徽章 + 标题 + ✎正在编辑(条件) + ⋮菜单 | 标题 + [定制](条件) + ⭐收藏 |
| 第2层 标签区 | 权限提示（实色） | 权限提示（实色）+ 自定义标签（描边） | 两类混合（同定制） |
| 第3层 信息区 | 执行次数 + ℹ | 执行次数 · 更新时间 + ℹ | 执行次数 + ℹ |

### 3.2 语义分层

| 层 | 职责 |
|---|---|
| 标题区 | 身份（版本/名称/状态/操作入口） |
| 标签区 | 属性（执行范围约束 + 用户自定义组织维度） |
| 信息区 | 统计 |

## 4. 「正在编辑」文字链规格（选项 A）

- **形态**：小铅笔图标（Edit）+ "正在编辑"纯文字，warning 色（#faad14），**无背景无边框**——与 tag 形态彻底区分
- **位置**：标题行内，标题（flex-1 省略）之后、⋮ 菜单之前；占宽约 70px
- **交互**：
  - 点击 → 触发 `viewDraft` command（切换到"我的草稿" tab + 打开草稿只读预览），与 ⋮ 菜单「查看草稿」同一 command，不新增逻辑
  - hover 出下划线提示可点
  - `@click.stop` 不触发卡片点击
- **无草稿时**：该元素不存在，标题行自然收缩
- **表格视图**：「编辑状态」列维持 tag 形态不变（表格列内 tag 是标准表达，无拥挤问题）
- **⋮ 菜单**：「查看草稿」项保留（同一 command 的双入口）

## 5. 尺寸规格

| 项 | 现状 | 方案 | 说明 |
|---|---|---|---|
| grid 最小列宽 | 220px | **280px** | 标签单行可容 4-5 个；1200px 内容区约 4 卡/行（原 5 卡/行） |
| 卡片 min-height | 80px | **104px** | 三层内容 + 间距的自然高度 |
| 卡片内边距 | 16px | **16px 20px** | 左右加宽，呼吸感 |
| 层间距 | 4px | **8px** | 属性边界清晰（8点网格） |
| tag 规格 | 20px 高 / 12px 字 | 不变 | 标签区 gap 6px |
| 圆角 | 4px | **8px**（$uops-radius-md，小卡片规范） | 对齐 UI 规范 |

**标签溢出规则**：标签区最多 2 行，超出折叠为 `+n`（tooltip 展开全部）——定制卡满配 8 个 tag 时 280px 宽约 2 行正好容纳，极端情况兜底。

## 6. 影响范围与不动项

**改动**：
1. `workbench.scss` 卡片样式 —— ⚠️ 该文件存在历史重复段（3-735 与 1476-2208 完全相同），**两处需同步改**
2. `index.vue` 公共组件/应用定制/收藏卡片模板重排
3. 「正在编辑」从标签区元素改为标题区文字链，点击处理复用 `handleCustomCommand({ action: 'viewDraft' })`

**不动**：
- 草稿卡片：同 grid 自动变宽，结构不动（有勾选框+状态列，布局逻辑不同）
- 表格视图（双视图设计不受影响）
- 卡片点击行为、TagEditPopover 挂载点（标签区仍是 popover reference）
- 收藏/取消收藏、执行弹窗等交互

## 7. 决策记录

| 问题 | 决策 |
|---|---|
| 标签区是否按类型拆行 | 不拆。实色 vs 描边视觉编码足够区分；组标签属双重编码，降低密度 |
| 「定制」徽标去处 | 应用定制 tab 内去掉；收藏区保留（混合列表需区分来源） |
| 「正在编辑」形式 | 选项 A 文字链（标题区，warning 色纯文字+铅笔图标，可点→viewDraft）；否决选项 B 指示点（入口隐蔽，可发现性差） |
| 列宽取舍 | 280px（推荐值，优化目标就是"不挤"；260px 备选留档） |
